# JavaScript DSA Learning Journey 🚀

A comprehensive collection of Data Structures and Algorithms problems in JavaScript, designed to improve your coding skills from beginner to advanced level.

## 📚 Project Structure

```
JavaScript_DSA/
├── Questions/
│   └── questions.txt          # 100 DSA problems (beginner to advanced)
├── Answers/                 
│   ├── 1.js                  # Individual problem solutions
│   ├── 2.js
│   └── ...
├── .env                      # Environment configuration
├── .gitignore               # Git ignore rules (keeps solutions private)
└── README.md               # This file
```

## 🔧 Environment Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/JavaScript_DSA.git
   cd JavaScript_DSA
   ```

2. **Configure your environment:**
   - Copy `.env` file and customize your settings
   - Adjust learning preferences and goals

3. **Start solving:**
   - Read problems in `Questions/questions.txt`
   - Create your solution files in `Answers/` folder
   - Your solutions will be kept private (not pushed to Git)

## 🚫 Privacy Protection

Your solution files are automatically excluded from Git commits:
- All files in `Answers/` folder
- Any files ending with `-solutions.js` or `-solution.js`
- Personal notes and practice files
- Environment configuration files

This ensures you can:
- Keep your solutions private
- Share the question structure with others
- Collaborate on problem sets without revealing answers

## 📖 How to Use

1. **Read the problem** from `Questions/questions.txt`
2. **Create solution file** in `Answers/` folder (e.g., `1.js` for problem 1)
3. **Implement your solution** with proper comments
4. **Test your code** with the provided examples
5. **Analyze time/space complexity**
6. **Move to the next problem**

## 🎯 Study Tips

- Start with beginner problems and progress gradually
- Focus on understanding patterns rather than memorizing solutions
- Practice regularly and consistently
- Time yourself to improve speed
- Write clean, readable code with comments
- Analyze different approaches for each problem
- Review and optimize your solutions

## 🏆 Progress Tracking

Use the `.env` file to customize your learning experience:
- Set daily problem targets
- Enable progress tracking
- Configure difficulty progression
- Set study session timers
